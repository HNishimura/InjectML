# **1‑online README**

### *Design‑Time Meaning Development (HCMD‑Aligned)*

**Version:** 2026‑08‑19

---

## **Purpose of 1‑online**

The **1‑online** directory contains the *design‑time* conceptual work used to prepare structured meaning before deterministic execution.  
It represents the **online stage** of the HCMD pairing:

- **Online = design‑time meaning development**  
- **Offline = deterministic runtime execution**

This pairing is intentional and mirrors the structure used in InjectML and PairWise.

The online stage is where meaning is stabilized, structured, and prepared.  
The offline stage is where the prepared structure is executed deterministically.

1‑online is here because it is one half of this public pairing.

---

## **Role in the InjectML Ecosystem**

InjectML demonstrates deterministic meaning injection into offline models.  
To achieve this, InjectML relies on a structured design‑time process:

- clarifying meaning  
- stabilizing meaning  
- defining structured tasks  
- preparing deterministic artifacts  
- ensuring reproducibility  

These activities occur in **1‑online**.

InjectML’s public examples (such as PairWise) use the results of 1‑online, but do not expose internal HCMD layers.  
1‑online provides the conceptual scaffolding needed to understand how structured meaning becomes deterministic behavior.

## **Online ↔ Offline Pairing**

The online stage prepares meaning.  
The offline stage executes meaning.

This pairing is central:

| Stage       | Description                     | Tool           |

| **Offline** | Deterministic execution         | Ollama         |

- **wine ↔ dish**
